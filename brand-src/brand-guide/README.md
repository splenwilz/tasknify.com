# Brand guide

Source for public/brand/tasknify-brand-guide.pdf (10 pages, A4). Edit guide.html, then
`sh brand-src/brand-guide/render.sh`. Image paths are written as `ROOT/...` and resolved by the script.
The Applications page uses thumbnails of the proposal sample, so render brand-src/proposal first
(`node brand-src/proposal/render.mjs brand-src/proposal/sample.json`). Needs Google Chrome and pdftoppm.
