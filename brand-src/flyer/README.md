# Flyer

One-page A4 flyer in the banner style. Edit flyer.html, then `sh brand-src/flyer/render.sh`, which writes
public/brand/flyer-a4.pdf (print, no bleed) and public/brand/flyer-a4.png (1588x2246 preview for email and chat).
Contact details are at the bottom of flyer.html; stats and recent work are in the body.
